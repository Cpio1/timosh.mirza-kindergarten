# Timosh Mirza — сайт детского сада

Next.js 15 · TypeScript · Tailwind CSS v4 · Framer Motion · Lucide React. Деплой — Vercel (настройки по умолчанию).

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
```

## Устройство

- `src/website/` — композиция для ноутбуков и мониторов (≥ 1024px).
- `src/mobile-website/` — отдельная композиция для телефонов (< 1024px).
- `src/shared/` — общее: данные (`data/kindergarten.ts`), переводы KZ/RU (`i18n/`), UI-элементы, хуки, утилиты.
- `src/shared/ui/LayoutSwitch.tsx` выбирает версию по ширине экрана (не по user agent). Сервер отдаёт обе, CSS сразу
  показывает нужную, после загрузки лишняя версия удаляется из DOM.

Все факты о детском саде — только в `src/shared/data/kindergarten.ts` и словарях `src/shared/i18n/kk.ts` / `ru.ts`.
Казахский — язык по умолчанию; выбор языка запоминается в браузере.

## Фотографии и видео

Положите файлы в `public/images/` (видео можно и в `public/videos/`) и задеплойте заново — код менять не нужно:

| Файл | Где используется |
| --- | --- |
| `main-page.*` | главный экран (фото или видео) |
| `main-page2.*` | фото → раздел «Біз туралы / О нас»; видео → небольшое беззвучное фоновое видео на главном экране (тогда в «О нас» встаёт первое фото галереи) |
| другие фото | галерея, по имени файла (`image1.jpeg`, `image2.jpeg`, …); сначала 6 (на телефоне 4), остальные — «Показать ещё» |
| другие видео (`.mp4`, `.webm`, `.mov`) | блок «Бейнежазбалар / Видео» под фотографиями галереи; запуск только по нажатию, со звуком и кнопками управления |

- Обложка для видео: файл `<имя>-poster.jpg` рядом с видео (например `video1.mp4` + `video1-poster.jpg`).
  Без обложки показывается первый кадр. Пропорции видео (включая вертикальные с телефона) определяются автоматически.
- Фоновое видео всегда `muted`, `playsInline`, `loop`, `autoPlay`, играет только пока видно на экране и не запускается
  при «экономии трафика» или «уменьшении движения».
- Видео лучше сжимать до 720p H.264, например:
  `ffmpeg -i input.mov -vf "scale=-2:720" -c:v libx264 -crf 26 -preset slow -c:a aac -b:a 96k -movflags +faststart video1.mp4`
  и обложку: `ffmpeg -i video1.mp4 -frames:v 1 -q:v 3 video1-poster.jpg`.
- Не кладите в `public/` сохранённые веб-страницы (`.html` + папка `_files`): всё из `public/` публикуется на сайте.

Форматы фото: jpg, png, webp, avif, gif. Поворот (EXIF) учитывается, одинаковые файлы показываются один раз.

## Документы (Google Drive)

Вставьте ссылку на папку в `kindergarten.documents.driveUrl` (`src/shared/data/kindergarten.ts`).
Пока ссылка пустая, вместо кнопки показывается «Сілтеме жақында қосылады / Ссылка скоро появится».

## Карта 2GIS

Метка стоит на карточке 2GIS «Тимош Мырза, частный детский сад» (`twoGis` в `kindergarten.ts`).
**Внимание:** в 2GIS эта карточка записана по адресу «Кольди, ул. Алмалы, 23», а детский сад указывает «ул. Алмалы, 15»
(дома № 15 на этой улице в 2GIS нет). На сайте показан адрес детского сада. Если метку нужно перенести, замените
`firmId`, `lat`, `lng`.
